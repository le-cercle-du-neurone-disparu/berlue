# ex-007 — vérité-terrain : VRAIE — **échec du RAG, verdict final faux**

**Q** : What genre is The Warriors Gate?
**R** : `action`

## Extraction — formulation bancale
`The Warriors Gate is an action genre.`

Un film n'**est** pas un genre, il *appartient* à un genre. L'affirmation correcte serait
`The Warriors Gate is an action film`. La reformulation maladroite rend l'affirmation plus
difficile à apparier, aussi bien pour le NLI que pour le RAG.

## SelfCheck — divergence 0,15, plutôt juste
Les échantillons hésitent sur l'étiquette exacte (arts martiaux, fantasy, science-fiction
hongkongaise) mais mentionnent tous « action » parmi les genres. Divergence faible, cohérent.

## RAG — confusion d'entité, et 0,99 de confiance
Extraits : *Overwatch*, *Divergent*, *XXx* — des films d'action, mais aucun rapport.

> « the Warriors Gate is **a location in the World of Warcraft universe**, and it is not an
> action genre. It is a place, not a movie »

Le modèle confond le film de 2016 avec un lieu de jeu vidéo, et rend `LIKELY_FALSE` à **0,99**.
Aucune trace de doute dans le raisonnement, alors que l'entité est ambiguë et que la base
n'apporte rien.

## Fusion — CONTRADICTED 0,71 : **faux**
SelfCheck penchait vers le vrai (0,15), le RAG catégorique vers le faux. L'arbitrage donne
raison au RAG, qui a tort. Le poids plus fort accordé au RAG se retourne ici contre le système.

## Défauts
| étage | défaut |
|---|---|
| Extraction | reformulation incorrecte (« is an action genre » au lieu de « is an action film ») |
| RAG | **confusion d'entité** (film ↔ lieu de jeu vidéo) sans aucune expression de doute |
| RAG | 0,99 de confiance sur une entité ambiguë et sans preuve en base |
| Fusion | un RAG catégoriquement faux l'emporte sur un SelfCheck correct |
